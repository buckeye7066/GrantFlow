# Expert Grant Writing with Anya: Strategic Matching

## Overview

When Anya helps write grants, she applies a **strategic-matching methodology**
modeled on how experienced grant writers approach a proposal: aligning funder
priorities with organizational strengths, not just filling in a template.

### Core techniques the methodology applies
1. **Strategic Analysis** — understanding funder motivations and institutional biases
2. **Needs-Gap Matching** — precise alignment of funder requirements with applicant strengths
3. **Competitive Intelligence** — what tends to distinguish winning proposals in a given funder category
4. **Storytelling with Data** — narratives backed by evidence already present in the profile
5. **Compliance & Detail** — adherence to funder requirements
6. **Positioning** — framing the proposal around the funder's stated and implicit goals

## Three Levels of Grant Writing

### Level 1: Basic (Template-Based)
**What to avoid**
- Generic boilerplate about the organization
- Generic needs statement
- Generic evaluation metrics
- "We will use funds to improve X"
- No funder-organization alignment

### Level 2: Good (Customized)
**What most grant writers do**
- Customized for each funder
- Organization-specific details
- Specific outcomes and metrics
- Funder-customized language

### Level 3: Strategic Matching — the approach Anya follows
- Analysis of the funder's stated and implicit priorities
- A gap analysis: "What does the funder need that the applicant has?"
- Positioning the organization as a fit for the funder's stated goals
- A sustainability narrative
- Competitive differentiation, grounded in facts already on the profile
- Evaluation language that mirrors the funder's own stated success metrics

## The Strategic Matching Process

### Step 1: Funder Intelligence Analysis

**What Anya analyzes** — using only facts available from the funder's own
published materials (RFP, prior awards, stated priorities) and the
applicant's profile, never invented facts about either side:

```
Funder Profile
├── Official stated priorities (explicit)
├── Implicit priorities (reading between the lines, where evidenced)
├── Recent funded projects, if published (pattern reference)
├── Geographic/sector focus
├── Average grant size & timeframe, if published
└── Known application requirements and common rejection reasons, if published
```

**Example (illustrative only — not a claim about any real funder):**
```
Foundation: [Example Foundation]
Stated Priority: "Global Health"
Possible implicit priorities to check for, if evidenced by the funder's own materials:
- Scalability
- Evidence of impact (rigorous design)
- Strong local partners
- Clear sustainability plan
- Reasonable overhead ratio
```

### Step 2: Organization-Funder Gap Analysis

**Mapping exercise** — every right-hand claim must come from the applicant's
own profile data, never invented:

```
Funder Need              →   Does the profile show it?   →   Positioning
────────────────────────     ──────────────────────────      ──────────────
"Scalability"             →   Regional base, proven model  →   State the actual
                                                                 footprint the
                                                                 profile records
"Evidence of impact"      →   Outcomes data on file        →   Cite only data
                                                                 the profile has
"Local implementation"    →   Board/community ties on file →   Cite only ties
                                                                 the profile has
"Sustainability plan"     →   Revenue mix on file          →   State the actual
                                                                 mix on file
```

**Critical rule:** if there's no genuine match in the profile, Anya says so —
it is better to flag a weak fit or recommend a different funder than to
fabricate alignment the organization cannot back up.

### Step 3: Strategic Positioning

Instead of a generic statement:
> "Our organization will provide educational programs to underserved youth."

Anya positions concretely, using only facts on the profile:
> A sentence that states the district's actual reach, the program's actual
> track record, and the actual cost/outcome figures on file — never invented
> percentages, dollar multipliers, or partnership claims that aren't in the
> applicant's data.

### Step 4: Funder Success Metrics Integration

**Not:** "We will measure outcomes using X, Y, Z metrics."

**Better:** evaluation language mirrored to the funder's own stated success
factors, with every number sourced from the applicant's actual data — never
a target Anya invents to sound impressive.

## Anya's Expert Grant Writing Checklist

### BEFORE Writing
- [ ] Reviewed the funder's own published guidance and any publicly available prior-grant information
- [ ] Identified competitive advantages the profile can actually document
- [ ] Mapped organization strengths to funder priorities (gap analysis)
- [ ] Flagged any funder requirement the profile cannot currently satisfy

### DURING Writing (Every Section)
- [ ] Does this section address a stated or well-evidenced funder priority?
- [ ] Is every fact traceable to the profile's own data?
- [ ] Does the tone match the funder's own materials?
- [ ] Is the sustainability plan concrete and specific to this applicant?

### BEFORE Submitting
- [ ] RFP/guidelines compliance checklist complete
- [ ] Requested amount matches what the profile actually needs — not padded, not underestimated
- [ ] No claim in the draft is unsupported by profile data
- [ ] Sustainability plan doesn't rely on "finding another funder"

## Implementation notes

Anya's drafting prompts instruct the model to analyze the funder, map
genuine alignment, and position the application around facts the profile
actually contains — and explicitly to say so, rather than invent alignment,
when a good match isn't there. The prompts do not instruct the model to
claim personal credentials, a specific historical win rate, or dollar
figures it has not verified against the applicant's own records.
