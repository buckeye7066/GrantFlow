# Browser evidence

These are actual Chromium screenshots of authenticated, synthetic non-admin fixture users on the loopback test server, not design mockups or production-user screenshots.

Before: repository commit 3cd6c490b8b01dfb3dc7dd7ae1598cacc8d0fc1e. After: the implementation committed with this folder. Both use the same isolated backend fixture and real password login.

Viewports: phone 390 x 844; portrait tablet 768 x 1024; desktop 1440 x 1000. Images are full-page captures. Exact scrolling and saved resume destinations can differ because the browser journeys exercise navigation.

Automated layout checks verify that the after view does not overflow horizontally. These screenshots are controlled browser QA, not human usability research.
