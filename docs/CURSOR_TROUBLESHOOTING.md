# Cursor/Composer 'Internal Error' Mitigation

## Runbook

1. **Limit Scope**: Narrow down the area of the request to prevent excessive strain on the system.
2. **Avoid Huge Review Sets**: Aim to break down large review sets into smaller, manageable chunks.
3. **Rebuild Index**: After making changes to `.cursorignore`, ensure to rebuild the index to avoid inconsistencies.
4. **Contacting Support**: When reaching out to Cursor support, always include the 'Copy Request' ID for quicker resolution.
